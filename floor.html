Clock Health

This node keeps its own clock between wake-ups and re-syncs from the root each cycle. Sync age is how long since it last heard a TIME_SYNC; from that it predicts its worst-case drift and wakes that much earlier, so its receive window still overlaps the root's. A growing age means the node is losing contact — check group ID, PHY and range.

Calibration mode pauses all mesh activity so SPP communication is not interrupted during configuration. Writes to Meter Config and the Calibration Table are only allowed while calibration mode is active.

Enter the secret code to unlock. The mode is cleared on SPP disconnect or reboot — it is not persisted to flash.

Applies immediately, no reboot. LEGACY: one legacy connectable advert on 1M. CODED: the legacy advert stays (so phones can still connect) plus a Coded S8 connectable advert that chain hops use. Put the target node in CODED and you can test both PHYs against it from here with PHY = Both. Pause the chain on the node you test from so its periodic cycle does not interrupt a run (cleared by reboot).

Adv = RSSI of the target's advert seen here. Link (this / target) = median connection RSSI measured at each end. Link PHY should read S8 on Coded. Failures show the stage: SCAN (target not heard on that PHY — is it in CODED mode?), CONNECT, MTU, ECHO (no reply), DROP. Att = tries used (a D after it = connected directly, without a scan). With Direct, Connect ms includes hearing the target. A raw hex Link PHY means the stack reported an unexpected value. Same thing from any terminal: LINK_TEST=2,10,64,B,D2 (add W to run detached, then LINK_TEST_RESULTS after reconnecting).
