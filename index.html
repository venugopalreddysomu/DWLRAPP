Connect to a water level recorder

Configure, calibrate, test the 4G link and download data over Bluetooth.

  1. Power the device and stand within a few metres of it.
  2. Press Connect and pick DWLR-xxxxxx.
  3. Enter the 6-digit PIN the device display shows after you connect.

Works in Chrome or Edge on Android, Windows, macOS and ChromeOS (Web Bluetooth). Open from a local file or an https address.

This browser does not support Web Bluetooth. Use Chrome or Edge.

      Firmware update over Bluetooth local, no cloud or internet needed

      Install a new firmware file from this phone or laptop. Settings, calibration and logged data are kept. Measuring continues during the transfer. If the new firmware does not run properly for 2 minutes after the restart, the device returns to the current firmware by itself.

      Use the application file dwlr_fw.bin (not merged-binary.bin). Keep the phone within a few metres and the screen on; it takes about 3–5 minutes.
